    GitHub connection

    Stored only in this browser. Never sent anywhere except api.github.com.

    Setup (one time)

    1. In GitHub: profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Resource owner: AmeristarWebDev. Expiration: up to a year. Repository access: Only select repositories → pick find-your-team and territorymap.
    3. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
    4. Generate, copy the token (starts with github_pat_), paste it here, tick Remember, click Connect.

    How saving works

    Every change you make is held in this page until you click Save to GitHub. Saving commits the data files (and any new headshots) directly to the repos. GitHub Pages republishes in about a minute; the AEM-embedded pages pick it up after the usual cache window.

    Nothing here edits the page code — only data/team.json, data/map.json and the image folders — so there's nothing to break. If anything ever goes wrong, every save is a normal commit you can revert on GitHub.
